	1	Explain in 2–3 sentences why the team should use TypeScript instead of plain JavaScript.
Ans - TS provides Type safety and can help prevent bugs which can occur due to no type definition in Javascript. It can help find issues and for any mismatch of type during compile time and can highlight syntax for any red flags. 
Ex - In Javscript, sometimes we don’t know what value will be coming from API , so we can predict which method to apply. If data is array and by expecting object we applied object methods on it, so it would be detected only during runtime. TS helps to resolve such problems by providing strict type safety.
